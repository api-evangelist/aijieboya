# Aijieboya (Agilebio) — Suzhou Aijie Boya Technology Co., Ltd. / 苏州艾捷博雅科技有限公司

> A Suzhou Industrial Park manufacturer of chromatography separation and purification
> technology, founded in 2020. It makes high-purity spherical silica gel chromatographic
> media, magnetic solid-phase extraction (mSPE) consumables and precision fluid automation
> instruments for biopharmaceutical manufacturing, clinical mass spectrometry, peptide and
> nucleic-acid drug purification, natural product extraction and food testing. Brands:
> Agilebio and Biosepur.

## No API surface

Aijieboya publishes NO public API, SDK, developer portal, OpenAPI/Swagger document,
GraphQL endpoint, MCP server, A2A agent card, webhook catalog or `/.well-known/`
document. This was measured on 2026-09-14 by probing every candidate path against
agilebio.com.cn and www.agilebio.com.cn; all returned 404 or did not answer. If you are
an agent looking for a callable interface here, there is not one — use the contact form.

The company's site runs WordPress, but its REST API at `/wp-json/` does not respond
(request hangs past 180s). The site is served over plaintext HTTP only; there is no TLS
listener on port 443.
